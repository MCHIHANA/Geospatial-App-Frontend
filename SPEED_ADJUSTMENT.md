# Speed Adjustment for Realistic Travel Times

## Issue
- User reported: Zomba to Kasungu shows 19h 10min
- Reality: Should be ~7 hours
- Problem: Default speed was 30 km/h (too slow)

## Solution
- Changed default speed from 30 km/h to 60 km/h
- This provides more realistic travel time estimates

## Impact
- Travel times will be approximately 2x faster
- 19h 10min → ~9-10 hours (closer to reality)
- User can restart backend to apply changes
